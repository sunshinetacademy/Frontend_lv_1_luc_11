ما هو Responsive Web Design؟

📖 التعريف

Responsive Web Design (RWD) هو نهج في تصميم المواقع يخلي الموقع يتكيف تلقائياً مع حجم شاشة المستخدم — سواء موبايل، تابلت، أو كمبيوتر.

بدلاً من بناء 3 مواقع مختلفة، بنعمل موقع واحد يتغير شكله حسب الشاشة.

💡 تشبيه من الحياة

تخيل إنك بتشتري هداية:

  • Non-Responsive = 3 هدايا مختلفة الأحجام (صغير، وسط، كبير) — مكلف وصعب
  • Responsive = هداية واحدة مرنة تتمدد وتنكمش حسب حجم الصندوق — ذكي وعملي
60%
من زيارات الإنترنت من الموبايل
80%
من المستخدمين بيتركوا موقع مش متجاوب
#1
RWD من أهم عوامل SEO في Google

✅ ليه RWD مهم؟

1. تجربة المستخدم: الموقع سهل الاستخدام على أي جهاز.

2. SEO: Google بيحب المواقع المتجاوبة ويرفعها في النتائج.

3. تكلفة أقل: موقع واحد بدل 3.

4. صيانة أسهل: تحديث واحد لكل الأجهزة.

5. معيار صناعي: أي شركة بتطلب RWD.

الأجهزة والمقاسات (Breakpoints)

📖 أنواع الأجهزة

في 3 أنواع رئيسية من الأجهزة، كل واحد ليه مقاس شاشة مختلف:

📱

Mobile

< 768px

الموبايلات — شاشات صغيرة، تفاعل باللمس

📱

Tablet

768px - 1024px

التابلت — شاشات متوسطة، لمس + كيبورد

💻

Desktop

> 1024px

الكمبيوتر — شاشات كبيرة، ماوس + كيبورد

📏 خريطة الـ Breakpoints

📱 Mobile
📱 Tablet
💻 Desktop
0px 768px 1024px 1440px+

🔍 Breakpoints شائعة

Breakpoint الجهاز مثال
< 576px موبايل صغير iPhone SE
≥ 576px موبايل كبير iPhone 14
≥ 768px تابلت iPad
≥ 992px ديسكتوب صغير Laptop
≥ 1200px ديسكتوب كبير Desktop Monitor
≥ 1400px شاشة Extra Large 4K Monitor

💡 ملاحظة مهمة

الأرقام دي مش ثابتة — كل مشروع ليه breakpoints مختلفة حسب التصميم. الأهم إنك تختار نقاط التغيير بناءً على شكل التصميم مش على أجهزة معينة.

🎛️
Media Queries — قلب الـ Responsive

📖 ما هي Media Queries؟

Media Queries هي طريقة في CSS عشان نطبق قواعد مختلفة حسب خصائص الجهاز (عرض الشاشة، الاتجاه، الدقة، وغيرها).

باختصار: "لو الشاشة عرضها كذا، طبق الـ CSS ده."

CSS — Syntax الأساسي 
@media (condition) {
    /* CSS يطبق بس لو الشرط اتحقق */
}

/* مثال: لما الشاشة أقل من 768px */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

🔍 أنواع الشروط

Condition المعنى الاستخدام
max-width: 768px الشاشة أقل من أو تساوي 768px Desktop-first (للموبايل)
min-width: 768px الشاشة أكبر من أو تساوي 768px Mobile-first (للتابلت والديسكتوب)
min-width: 768px) and (max-width: 1024px الشاشة بين 768px و 1024px للتابلت فقط
orientation: landscape الشاشة أفقية للتابلت والموبايل الأفقي
orientation: portrait الشاشة رأسية للموبايل العمودي
CSS — أمثلة شاملة 
/* ===== Mobile-first approach ===== */

/* Default (Mobile) */
.container {
    padding: 1rem;
    font-size: 14px;
}

.grid {
    display: grid;
    grid-template-columns: 1fr; /* عمود واحد */
}

/* Tablet (≥ 768px) */
@media (min-width: 768px) {
    .container {
        padding: 2rem;
        font-size: 16px;
    }
    
    .grid {
        grid-template-columns: 1fr 1fr; /* عمودين */
    }
}

/* Desktop (≥ 1024px) */
@media (min-width: 1024px) {
    .container {
        max-width: 1200px;
        margin: 0 auto;
    }
    
    .grid {
        grid-template-columns: repeat(3, 1fr); /* 3 أعمدة */
    }
}

⚠️ ترتيب الـ Media Queries مهم!

في Mobile-first: ابدأ من الأصغر للأعلى (min-width).

في Desktop-first: ابدأ من الأكبر للأصغر (max-width).

الترتيب الخاطئ هيخلي القواعد متتغلب على بعض!

📱
Mobile-First Approach

📖 ما هو Mobile-First؟

Mobile-First يعني إنك تبدأ التصميم من الموبايل (الشاشة الأصغر)، وبعدين تضيف تعديلات للشاشات الأكبر باستخدام min-width.

📱

Mobile-First ⭐

نبدأ من الموبايل، ونبني للأعلى

✓ أداء أفضل (CSS أقل للموبايل)
✓ يركز على المحتوى الأساسي
✓ أسهل في الصيانة
✓ متوافق مع Google (Mobile-first indexing)
⭐ الأفضل — المحترفين بيستخدموه
💻

Desktop-First

نبدأ من الديسكتوب، ونبني للأسفل

✓ أسهل للمبتدئين أحياناً
✗ CSS زيادة للموبايل
✗ أداء أقل
✗ صيانة أصعب
⚠️ قديم — تجنبه
CSS — Mobile-First Pattern 
/* ===== Mobile-First Pattern ===== */

/* 1. Default styles (Mobile) — يشتغلوا دايماً */
.navbar {
    display: flex;
    flex-direction: column; /* عمودي في الموبايل */
    padding: 1rem;
}

/* 2. Tablet — min-width: 768px */
@media (min-width: 768px) {
    .navbar {
        flex-direction: row; /* أفقي في التابلت */
        padding: 1.5rem;
    }
}

/* 3. Desktop — min-width: 1024px */
@media (min-width: 1024px) {
    .navbar {
        padding: 2rem;
        max-width: 1200px;
        margin: 0 auto;
    }
}

✨ قاعدة Mobile-First الذهبية

1. اكتب CSS الأساسي للموبايل الأول (من غير media query).

2. استخدم min-width عشان تضيف تعديلات للشاشات الأكبر.

3. رتب الـ media queries من الأصغر للأكبر.

📏
Flexible Units — الوحدات المرنة

📖 ليه الوحدات المرنة مهمة؟

عشان التصميم يبقى متجاوب، لازم نستخدم وحدات مرنة بدلاً من px الثابت.

%
Percentage

نسبة من العنصر الأب. ممتاز للـ widths.

rem
Root Em

نسبة من حجم خط الـ root. الأفضل للـ font-size و spacing.

vw / vh
Viewport Units

نسبة من عرض/ارتفاع الشاشة. للـ Hero sections.

vmin / vmax
Viewport Min/Max

أصغر/أكبر بعد من أبعاد الشاشة.

clamp()
النطاق المرن

قيمة بين حد أدنى وأقصى. سحر الـ Responsive!

min() / max()
الحدود

أقل أو أكبر قيمة من مجموعة.

🔹 clamp() — السحر الحقيقي

clamp(min, preferred, max) — قيمة مرنة بين حد أدنى وحد أقصى.

ده أقوى tool في CSS الحديث للـ Responsive!

CSS — clamp() 
/* clamp(minimum, preferred, maximum) */

/* Font size responsive بدون media queries! */
h1 {
    font-size: clamp(1.5rem, 5vw, 3rem);
    /* 
       - أصغر حجم: 1.5rem (24px)
       - الحجم المفضل: 5vw (5% من عرض الشاشة)
       - أكبر حجم: 3rem (48px)
    */
}

/* Container width responsive */
.container {
    width: clamp(300px, 80%, 1200px);
}

/* Padding responsive */
section {
    padding: clamp(1rem, 5vw, 4rem);
}

🔹 min() و max()

min() = يختار الأصغر. max() = يختار الأكبر.

CSS — min() & max() 
/* min() = الأصغر من القيم */
.box {
    width: min(100%, 600px);
    /* العرض هيكون 100% أو 600px — أيهما أصغر */
    /* على الموبايل: 100% (أصغر من 600px) */
    /* على الديسكتوب: 600px (أصغر من 100%) */
}

/* max() = الأكبر من القيم */
.sidebar {
    width: max(250px, 20%);
    /* العرض هيكون 250px أو 20% — أيهما أكبر */
}

📊 متى نستخدم كل وحدة؟

الوحدة الاستخدام مثال
% Widths, Layouts width: 100%
rem Font sizes, Spacing font-size: 1.2rem
vw Hero sections, Responsive typography font-size: 5vw
vh Full-height sections height: 100vh
clamp() أي قيمة مرنة ⭐ clamp(1rem, 3vw, 2rem)
min() حد أقصى مرن min(100%, 600px)
max() حد أدنى مرن max(250px, 20%)

🖼️
Responsive Images — الصور المتجاوبة

📖 ليه الصور مهمة في RWD؟

الصور من أكبر أسباب بطء المواقع. لازم نتعامل معاها بحكمة عشان ما تكسرش الـ Layout على الشاشات الصغيرة.

CSS — Responsive Images 
/* القاعدة الذهبية: الصور ما تطلعش عن عرض الأب */
img {
    max-width: 100%;
    height: auto;
    display: block;
}

/* object-fit — للتحكم في شكل الصورة */
.cover-img {
    width: 100%;
    height: 300px;
    object-fit: cover; /* يملأ المساحة */
}

.contain-img {
    width: 100%;
    height: 300px;
    object-fit: contain; /* يظهر الصورة كاملة */
}

🔍 object-fit values

Value السلوك الاستخدام
cover يملأ المساحة — قد يقص الصورة Hero images, Cards
contain يظهر الصورة كاملة — قد يترك فراغات Logos, Products
fill يمدد الصورة (قد يشوهها) تجنبه
none الحجم الأصلي حالات خاصة

⚠️ نصيحة للأداء

• استخدم صيغ حديثة زي WebP (حجم أصغر).

• استخدم <picture> و srcset لتحميل مقاسات مختلفة حسب الشاشة (هنشوفهم في مستوى متقدم).

• دايماً حط loading="lazy" للصور اللي تحت الـ fold.

🔤
Responsive Typography — النصوص المتجاوبة

📖 خطوط تتكيف مع الشاشة

الخطوط الكبيرة على الديسكتوب ممكن تكون كبيرة جداً على الموبايل. لازم نتحكم في حجمها بشكل مرن.

CSS — Responsive Typography 
/* الطريقة القديمة: media queries */
h1 {
    font-size: 2rem; /* Mobile */
}

@media (min-width: 768px) {
    h1 { font-size: 2.5rem; } /* Tablet */
}

@media (min-width: 1024px) {
    h1 { font-size: 3rem; } /* Desktop */
}

/* الطريقة الحديثة: clamp() — سطر واحد بس! */
h1 {
    font-size: clamp(2rem, 5vw, 3.5rem);
}

h2 {
    font-size: clamp(1.5rem, 4vw, 2.5rem);
}

p {
    font-size: clamp(1rem, 2vw, 1.125rem);
}

✨ ليه clamp() أفضل؟

1. كود أقل: سطر واحد بدل 3 media queries.

2. أكثر سلاسة: الخط بيتغير تدريجياً، مش قفزات.

3. أداء أفضل: المتصفح مش محتاج يحسب media queries.

💡 نصيحة مهمة

متخليش الخط أصغر من 16px (1rem) للنص العادي. أصغر من كده بيصعب القراءة على الموبايل.

Responsive Layout Patterns

📖 أنماط Layout شائعة

في أنماط محددة بنستخدمها في الـ Responsive Design:

🔹 Pattern 1: Column Drop

الأعمدة بتترتب جنب بعض على الديسكتوب، وبتنزل تحت بعض على الموبايل.

CSS — Column Drop 
/* Mobile-first: عمود واحد */
.layout {
    display: grid;
    grid-template-columns: 1fr;
    gap: 1rem;
}

/* Tablet: عمودين */
@media (min-width: 768px) {
    .layout {
        grid-template-columns: 1fr 1fr;
    }
}

/* Desktop: 3 أعمدة */
@media (min-width: 1024px) {
    .layout {
        grid-template-columns: 1fr 2fr 1fr;
    }
}

🔹 Pattern 2: Layout Shifter

الـ Layout بيتغير تماماً حسب الشاشة — مش بس عدد الأعمدة.

CSS — Layout Shifter 
/* Mobile: Sidebar تحت المحتوى */
.page {
    display: grid;
    grid-template-areas:
        "header"
        "main"
        "sidebar"
        "footer";
}

/* Desktop: Sidebar جنب المحتوى */
@media (min-width: 1024px) {
    .page {
        grid-template-areas:
            "header  header"
            "sidebar main"
            "footer  footer";
        grid-template-columns: 250px 1fr;
    }
}

🔹 Pattern 3: Off-Canvas (Navigation)

القائمة بتكون مخفية على الموبايل، وتظهر كـ "hamburger menu".

CSS — Off-Canvas Nav 
/* Mobile: القائمة مخفية */
.nav-links {
    display: none;
}

.nav-links.active {
    display: flex;
    flex-direction: column;
    position: absolute;
    top: 100%;
    right: 0;
    left: 0;
    background: #4A7C59;
}

/* Desktop: القائمة ظاهرة */
@media (min-width: 768px) {
    .nav-links {
        display: flex;
        flex-direction: row;
        position: static;
        gap: 2rem;
    }
    
    .menu-toggle {
        display: none; /* إخفاء زر القائمة */
    }
}

💡 ملاحظة

زر الـ Hamburger محتاج JavaScript عشان يفتح ويقفل القائمة. هنشوف ده في مستوى JavaScript.

✅ Checklist للاختبار

1. اختبر على 3 مقاسات: 375px (موبايل)، 768px (تابلت)، 1440px (ديسكتوب).

2. تأكد إن كل النصوص مقروءة (مش صغيرة جداً).

3. تأكد إن الأزرار والروابط سهلة الضغط (44px × 44px على الأقل).

4. تأكد إن الصور ما طلعتش بره الـ Container.

5. تأكد إن الـ Forms سهلة الملء على الموبايل.

Debugging — اكتشف الأخطاء

🔍 نشاط: اكتشف الأخطاء في CSS ده

الكود ده فيه 5 أخطاء شائعة في Responsive Design.

CSS — كود فيه أخطاء ❌ 
/* Mobile-first approach */
.container {
    width: 1200px;
    font-size: 18px;
}

@media (max-width: 768px) {
    .container {
        width: 700px;
    }
}

img {
    width: 800px;
}

h1 {
    font-size: 48px;
}
❌ الأخطاء
1. width: 1200px ثابت (مش مرن)
2. Mobile-first لازم min-width
3. عرض الصورة ثابت (يكسر على الموبايل)
4. h1 بـ 48px كبير على الموبايل
5. مفيش max-width: 100% للصور
✅ الكود الصحيح
/* Mobile-first */
.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  font-size: clamp(14px, 2vw, 18px);
}
img {
  max-width: 100%;
  height: auto;
}
h1 {
  font-size: clamp(2rem, 5vw, 3rem);
}

📌 ملخص المحاضرة

  • Responsive Web Design = موقع واحد يتكيف مع كل الشاشات
  • Breakpoints: Mobile (< 768px), Tablet (768-1024px), Desktop (> 1024px)
  • Media Queries = @media (condition) { CSS }
  • min-width = Mobile-first (الأفضل)، max-width = Desktop-first
  • Mobile-first: ابدأ من الموبايل، وبنِ للأعلى بـ min-width
  • Flexible Units: %, rem, vw, vh, clamp(), min(), max()
  • clamp(min, preferred, max) = سحر الـ Responsive الحديث
  • Responsive Images: max-width: 100% + height: auto
  • object-fit: cover/contain للتحكم في شكل الصورة
  • Responsive Typography: clamp() بدل media queries
  • Layout Patterns: Column Drop, Layout Shifter, Off-Canvas
  • اختبر على أجهزة حقيقية + DevTools
  • Viewport meta tag لازم في كل صفحة

10 أسئلة لاختبار فهمك لمحتوى المحاضرة

سؤال 1

ما معنى Responsive Web Design؟

  • أ موقع سريع
  • ب موقع يتكيف مع كل أحجام الشاشات
  • ج موقع فيه حركات
  • د موقع فيه صور كتير
سؤال 2

ما هو الـ Breakpoint الخاص بالتابلت عادةً؟

  • أ 320px
  • ب 768px
  • ج 1440px
  • د 1920px
سؤال 3

ما هو الـ syntax الصحيح لـ Media Query؟

  • أ @screen (max-width: 768px) { }
  • ب @media (max-width: 768px) { }
  • ج @responsive (768px) { }
  • د @query max-width: 768px { }
سؤال 4

في Mobile-first approach، أي media query نستخدم؟

  • أ max-width
  • ب min-width
  • ج exact-width
  • د device-width
سؤال 5

ما هي وظيفة clamp()؟

  • أ تحدد قيمة ثابتة
  • ب تحدد قيمة مرنة بين حد أدنى وأقصى
  • ج تخفي العنصر
  • د تكبر العنصر تلقائياً
سؤال 6

إزاي تخلي الصورة متجاوبة؟

  • أ width: 100%
  • ب max-width: 100% + height: auto
  • ج object-fit: cover
  • د display: block
سؤال 7

ما هي الوحدة الأفضل لـ font-size متجاوب؟

  • أ px
  • ب em
  • ج rem أو clamp()
  • د pt

ما وظيفة object-fit: cover؟

  • أ يظهر الصورة كاملة
  • ب يملأ المساحة ويقص الصورة لو لزم
  • ج يكبر الصورة
  • د يخفي الصورة
سؤال 9

أي pattern بيخلي القائمة مخفية على الموبايل؟

  • أ Column Drop
  • ب Layout Shifter
  • ج Off-Canvas
  • د Flexbox

ليه Mobile-first أفضل من Desktop-first؟

  • أ أسهل للمبتدئين
  • ب أداء أفضل + يركز على المحتوى + متوافق مع Google

واجبات المحاضرة

5 مسائل تطبيقية متدرجة لتثبيت ما تعلمته

📌 الواجب الأول: Media Queries Basics

ابني صفحة بسيطة فيها box واحد:

  • على الموبايل: box أحمر، عرض 100%
  • على التابلت (≥ 768px): box أصفر، عرض 50%
  • على الديسكتوب (≥ 1024px): box أخضر، عرض 30%
  • استخدم Mobile-first approach (min-width)
  • اكتب تحت كل box شرح للـ breakpoint

📌 الواجب الثاني: Responsive Typography

ابني صفحة فيها:

  • h1 بـ clamp(2rem, 6vw, 4rem)
  • h2 بـ clamp(1.5rem, 4vw, 2.5rem)
  • h3 بـ clamp(1.2rem, 3vw, 2rem)
  • p بـ clamp(1rem, 2vw, 1.125rem)
  • جرب تغير حجم المتصفح وشوف الفرق
  • قارن مع نسخة بـ media queries — أيهما أفضل؟

📌 الواجب الثالث: Responsive Cards Layout

ابني Cards Layout متجاوب:

  • Grid بـ auto-fit + minmax(280px, 1fr)
  • 6 cards على الأقل
  • كل card فيها: صورة + عنوان + وصف + زر
  • Responsive images (max-width: 100%)
  • جرب على 3 مقاسات: 375px, 768px, 1440px

📌 الواجب الرابع: Responsive About Section

ابني About Section بـ Layout Shifter:

  • على الموبايل: صورة فوق + نص تحت (flex-direction: column)
  • على التابلت: صورة جنب نص (flex-direction: row)
  • على الديسكتوب: نفس التابلت لكن مع max-width + margin: 0 auto
  • استخدم clamp() للـ padding
  • Responsive image مع object-fit: cover
